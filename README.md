# ✮⋆˙ Portfólio — Designer de Interiores

Portfólio pessoal desenvolvido para apresentar informações profissionais, habilidades, ferramentas utilizadas e projetos de Design de Interiores.

## 🎯 Objetivo

O projeto foi desenvolvido com o objetivo de criar um portfólio online para apresentar:

- Informações sobre a profissional;
- Habilidades e ferramentas utilizadas;
- Projetos de Design de Interiores;
- Currículo para download;
- Formas de contato.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Boxicons
- Google Fonts
- FormSubmit

## ✨ Funcionalidades

- Página inicial com apresentação;
- Seção "Sobre mim";
- Download do currículo;
- Apresentação das ferramentas utilizadas;
- Galeria de projetos;
- Carrossel de imagens;
- Formulário de contato;
- Modo de visualização;
- Menu responsivo para dispositivos móveis.

## 🧰 Ferramentas utilizadas

O portfólio apresenta conhecimentos e utilização das seguintes ferramentas:

- GitHub
- Visual Studio Code
- SketchUp
- AutoCAD

## 🖼️ Projetos

A seção de projetos apresenta diferentes trabalhos de Design de Interiores, incluindo:

- Sala de estar;
- Cozinha;
- Canto de descanso.
